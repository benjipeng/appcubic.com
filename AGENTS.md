# AppCubic website

This static Astro site serves https://www.appcubic.com. Keep the homepage,
workshop overview, and About routes stable. Source and private working reports
belong in their existing brand workspace; account observations stay outside
this public repository.

- Publish complete, readable HTML. JavaScript enhances presentation, never
  creates required content or links. Keep native scrolling and an explicit
  motion control, reduced-motion support, and a complete script-free fallback.
- Body text and controls must remain readable on phones. Keep body copy at
  least 16px, use sufficient contrast, and preserve generous touch targets.
  Display typography may be expressive and intentionally cropped.
- Project facts and addresses come from the validated App Automaton catalog at
  build time. Editorial selection is explicit. Never invent project URLs or
  make blanket claims about project licenses or model terms.
- Use original or appropriately licensed art and local fonts with recorded provenance. Blender is an
  optional authoring tool, not a production build or browser dependency.
- Preserve normal followable links, canonical URLs, sitemap behavior, and
  social metadata. Run publication checks and a production build before merge.
- Keep code, comments, and documents in English. Avoid mid-sentence em dashes.
- The primary agent owns implementation and review. Do not use subagents.
